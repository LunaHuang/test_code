# 待辦清單

命令列待辦清單：新增待辦事項、標成完成、刪除，並列出整份清單。

## Language

**待辦清單**:
所有待辦事項的集合，存放在一個資料檔裡。
_Avoid_: 任務列表、todo list

**待辦事項**:
清單中的一筆，有 id、標題、是否完成與建立時間。
_Avoid_: 任務、項目、task

**id**:
待辦事項的編號，新增時依序發號，永遠遞增；刪除後不會被重複使用。
_Avoid_: 序號、位置、第幾個

**標題**:
待辦事項的文字內容，不可為空白。
_Avoid_: 內容、名稱、描述

**完成**:
待辦事項的狀態；只能從未完成變成完成，不能取消。
_Avoid_: 勾選、結束、done（只用在指令名稱）

**資料檔**:
存放待辦清單的 JSON 檔，位在執行目錄下的 `data/todos.json`。
_Avoid_: 資料庫、存檔
