# 伺服器不保存局的狀態，每次重新解題比對

伺服器不記錄任何一局。確認作答時，前端把題目與作答一起送上，伺服器當場解出題目的唯一解答再比對；按「顯示答案」時也只送題目。這樣不需要管理局的生命週期，伺服器重啟不影響進行中的局，解答也不會在開局時就出現在前端。9×9 題目重新解一次只需幾毫秒，成本可忽略。

## Considered Options

- **伺服器在記憶體保存每一局，前端只送局 ID**：需要處理過期清除，伺服器重啟就會遺失進行中的局。
- **開局時把解答一起送到前端比對**：最簡單，但用開發者工具就能看到解答。

## Consequences

日後若要加入計時、排行榜或防作弊，伺服器必須知道局的開始與結束，屆時需要改為由伺服器保存局，並取代本決定。
